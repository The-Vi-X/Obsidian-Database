
| command | what mean              | description                                                                                            |
| ------- | ---------------------- | ------------------------------------------------------------------------------------------------------ |
| `jg`    | jump if greater        | jump to a specified location if a previous comparison indicates that one value is greater than another |
| `add`   | add                    | add two operands and stores results in destination operand                                             |
| `lea`   | load effective address | is used to calculate the address of a memory operand and store that address in a register              |
| `push`  | push                   | add a value to the top of the stack                                                                    |
| `call`  | call                   | call a procedure                                                                                       |
