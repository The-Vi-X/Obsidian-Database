
| command | what mean              | description                                                                                                       | examples                                                                                                                      |
| ------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| #push   | push                   | decrease #esp by 4 and copy data to new address of the top of the stack                                           | `push ebp` - cupy #ebp to top of the stack                                                                                    |
| #mov    | move                   | cope address from`source` to `destination`                                                                        | `mov destination, source`<br>`mov ebp, esp` - copy address from #esp to #ebp                                                  |
| #sub    | subtract               | subtract `data` from `register` of `memory`                                                                       | `sub register, data`<br>`sub esp, 0x81` - decrease esp at 129 bytes, (give free space on stack)                               |
| #test   | test                   | Perform bitwise AND without modifying operands<br>Sets flags ZF:<br>if result **zero** - ZF=0<br>else - ZF=1      | `test reg, bit`<br>`test eax, eax` - check if eax is zero                                                                     |
| #jne    | jump if not equal      | if previous ZF=0 - jump to address<br>else (ZF!=0) - don't jump, do next code block                               | `jne address`<br>`jne 0x8049234` - jump to `0x8049234` if ZF not equal to 0                                                   |
| #call   | call                   | call function and write to stack address for #ret                                                                 | `call address/function`<br>`call sym.imp.exit` - call exit function                                                           |
| #cmp    | compare                | decrease from operand1 operand2 and save result to ZF<br>if operands equal - ZF=1<br>if operands not equal - ZF=0 | `cmp var1, var2`<br>`cmp dword [var_8h], 0` - compare if var_8h equal to 0                                                    |
| #xor    | xor                    | Perform bitwise XOR on operand1 and operand2, and store the result in operand1                                    | `xor operand1 operand2`<br>`xor eax, eax`<br>operand1 = operand1 XOR operand2<br>                                             |
| #lea    | load effective address | store adress to operand1                                                                                          | `lea operand1 operand2`<br>store address of operand2 to operand1<br>`lea eax, [var_8h]`<br>store address of `[var_8h]` to EAX |
| #je     | jump if equal          | Jump to address if previous comparison result was **equal** (ZF=1).                                               | `je address`<br>jump to address if last compare is equal                                                                      |
|         |                        |                                                                                                                   |                                                                                                                               |
