Identify which accounts have administrative or root-level access. Check for default accounts that should have been disabled. Review password policy settings where accessible.<br><br>`File and directory permissions` - Search for files and directories with overly permissive access controls.<br><br>`Service configurations` - List all running services and their configurations. Identify which user account each service runs as. Check whether the service's binary or configuration file is writable by the current user.<br><br>`Scheduled tasks and cron jobs` - Enumerate all scheduled jobs and identify those running with elevated privileges. Check the permissions on any scripts or binaries referenced by privileged scheduled tasks.<br><br>`Credential storage` - Search for credentials stored in accessible locations. Check shell history files, environment variables, configuration files, registry entries, credential stores, and deployment files.<br><br>`Network configuration` - Review listening ports, bound interfaces, and rules. Identify services that are unnecessarily exposed or accessible. |
