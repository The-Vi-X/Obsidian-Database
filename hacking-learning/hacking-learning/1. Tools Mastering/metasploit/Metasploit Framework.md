#metasploit-framework


| Command          | Usage                                       |
| ---------------- | ------------------------------------------- |
| msfconsole       | activating metasploit framework             |
| search `service` | search exploit in framework to expluatation |
| use `number`     | start using exploit from search list        |
| show options     | show, what need to use for activate exploit |
| set RHOSTS `ip`  | set target ip as host for exploit           |
| show payloads    | show list of awiable payloads               |
| exploit          | run exploit5                                |
