`print $var` - печатает содержимое переменной
`x/s address` - показывает значение адресса
`info functions system` - поиск адреса функции, в данном случае system
`find address, +5000000, "func"` - поиск функции начиная с адресса
`x/s *((char **)environ)`- поиск глобальных переменных системы в программе после запуска
`info registers` - адреса регистров
